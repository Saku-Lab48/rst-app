# RSTトレーニング（リーディングスキル演習アプリ）

中学1〜3年生向けの、リーディングスキルテスト（RST）形式の演習アプリです。
国語・数学・社会・理科・英語の文章を使い、7つのリーディングスキル（RS1〜RS7）ごとに正答率を確認できます。

- サーバー不要の静的サイトです（GitHub Pages で公開します）。
- 問題データは **Excel（`data/source/*.xlsx`）** で管理し、アップロードすると自動でアプリに反映されます。
- 学習記録は、使っているブラウザの中（localStorage）に、学習者ごと・1問ごと（日時・正誤・選んだ答え・解答時間）に保存されます。
  サーバーには送られないため、別の端末とは共有されません。ブラウザの履歴・サイトデータを消すと記録も消えるので、ときどきバックアップを書き出してください。

---

## 1. 最初の公開手順（GitHub の Web 画面だけでできます）

1. GitHub で新しいリポジトリを作成します（例：`rst-app`）。
2. 「Add file」→「Upload files」で、このフォルダの中身を**すべて**アップロードします。
   - `.github` フォルダも必要です。見えない場合は、エクスプローラー／Finder で隠しフォルダを表示してからドラッグしてください。
   - ブラウザでフォルダのアップロードがうまくいかない場合は、GitHub Desktop を使うと確実です。
3. リポジトリの **Settings → Pages** を開き、「Build and deployment」の **Source** を **GitHub Actions** にします。
4. **Actions** タブで「Build data & deploy to GitHub Pages」が緑色のチェックになるまで待ちます（1〜2分）。
5. Settings → Pages に表示される URL（`https://<ユーザー名>.github.io/rst-app/`）を開くとアプリが使えます。

> 注意：リポジトリを公開（Public）にすると、Excel ファイルも誰でもダウンロードできます。
> 正答を見られたくない場合はリポジトリを Private にしてください（Private で Pages を使うには有料プランが必要です）。

## 2. 問題を追加・修正する方法

### 方法A：既存の Excel に行を追加して上書きする
1. `data/source/RST問題データベース.xlsx` をダウンロードし、「問題DB」シートに行を追加・修正します。
2. GitHub で `data/source/` を開き、「Add file」→「Upload files」で同じ名前のファイルをアップロードします（上書き）。
3. 「Commit changes」を押すと自動でアプリに反映されます。

### 方法B：新しい Excel ファイルを追加する（バッチごとに分ける）
- `data/source/` に置いた `.xlsx` は**すべて**読み込まれます。
- 例：`RST_B002.xlsx`、`RST_B003.xlsx` のようにバッチごとにファイルを分けて追加できます。
- 条件：シート名が「問題DB」で、1行目の列名が既存ファイルと同じであること。

### 列のルール（「問題DB」シート）

| 列名 | 必須 | 内容 |
|---|---|---|
| 問題ID | ○ | `JPN-0001` など。**全ファイルを通して重複不可** |
| 教科 | ○ | 国語／数学／社会／理科／英語 |
| 学年 | ○ | 中1／中2／中3 |
| 分野・単元 |  | 表示と検索に使用 |
| RSコード | ○ | DEP／ANA／PARA／INF／REP／INST_DIC／INST_SCI |
| RS項目 |  | 表示名（アプリ側でも自動で付きます） |
| 本文（素材文） | ○ | 読ませる文章・基準文・定義 |
| 補足・図表情報 |  | 前提条件など（※付きで表示） |
| 設問文 | ○ | |
| 選択肢A〜D | ○ | 4つすべて |
| 正答 | ○ | A／B／C／D |
| 根拠 |  | 解答後に表示 |
| 難易度 |  | 1〜3（空欄なら2） |
| バッチ |  | B001 など。空欄なら「未分類」 |
| レビュー状況 |  | **「要修正」にした問題はアプリに出ません** |

### データにミスがあったとき
問題IDの重複、正答が A〜D 以外、必須列の空欄などがあると、Actions が赤い×になり、**アプリは前の状態のまま**になります。
Actions タブで失敗した実行を開くと、「〇〇.xlsx 12行目: 正答「E」は A〜D ではありません」のように原因の行が表示されます。

## 3. パソコンで試す（任意）

```bash
pip install openpyxl
python scripts/build_data.py      # Excel → data/questions/*.json に変換
python -m http.server 8000        # http://localhost:8000 を開く
```
`index.html` をダブルクリックで直接開くと、ブラウザの制限でデータを読み込めません。

```

assets/style.css           デザイン
data/source/*.xlsx         ★問題データ（ここを編集・追加する）

data/manifest.json         読み込むJSONの一覧（自動生成）
scripts/build_data.py      Excel→JSON 変換・チェック
.github/workflows/deploy.yml  自動変換と公開の設定
```

## 5. アプリの機能

- **演習**：教科・学年・RS項目・問題数を選んで出題。解答するとすぐに正誤と根拠を表示。キーボード（1〜4 / A〜D、Enter）でも操作できます。
- **結果**：RS項目別の正答率、ふり返り、まちがえた問題だけの再挑戦。
- **ダッシュボード**：期間（7日・30日・90日・今月・先月・全期間・期間指定）を選んで学習履歴を表示します。
  - 解答数・正答率・学習日数（連続日数）・1問あたりの時間と、前の同じ長さの期間との差
  - 解答数と正答率の推移グラフ（日・週・月ごと。期間の長さで自動切りかえ／手動でも選択可）
  - リーディングスキル別の正答率と前の期間との差、教科×RSのヒートマップ
  - 正答率の低い組み合わせを「重点的に練習したいところ」として表示し、そのまま練習を開始
  - 演習ごとの記録（日時・教科・正解数・時間）
- **学習者の切りかえ**：1台の端末を複数人で使う場合は、ダッシュボードで学習者を追加・切りかえできます。
- **記録のバックアップ**：CSV（Excelで開ける解答ログ）と、バックアップファイル（JSON）の書き出し・読み込み。端末の引っ越しや、先生への提出に使います。
- **問題一覧**：教科・学年・RS・バッチ・キーワードで絞り込み、選択肢・正答・根拠を確認（先生・作成者向け）。
